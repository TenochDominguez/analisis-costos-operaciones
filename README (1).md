# Análisis Relacional de Asistencia y Recursos Comunitarios

**Herramientas:** SQL relacional · Hojas de cálculo

## El problema
En un evento juvenil de 516 participantes distribuidos en 22 grupos (compañías), se necesitaba dar seguimiento a inscripciones, recurrencia y reparto de suministros sin duplicados ni errores que afectaran la logística del día del evento.

## Qué hice
- Estructuré una base de datos relacional para dar seguimiento a métricas de recurrencia, voluntariado y participación.
- Formulé consultas con funciones de agregación (COUNT, SUM, GROUP BY) y filtros condicionales para detectar patrones de deserción (churn) y optimizar el reparto de suministros.
- Apliqué el mismo modelo para depurar registros duplicados y generar reportes oficiales de inscripción con desgloses por estaca y barrio.

## Resultado
Reportes confiables usados por las áreas de comedor, medicina, inclusión e instalaciones para planear compras, comidas, unidades de transporte e insumos con datos reales en vez de estimaciones.
